OPERACIONES UNARIAS DEL ÁLGEBRA RELACIONAL

Con ADO.NET Entity Framework y Northwind

El álgebra relacional es la base teórica de las bases de datos relacionales. Mediante Entity Framework y LINQ podemos implementar consultas declarativas eficientes utilizando la base de datos Northwind.

¿Qué es el Álgebra Relacional?

Es un conjunto de operaciones que permite manipular datos en bases de datos relacionales mediante relaciones o tablas.

Entity Framework

ORM de Microsoft que facilita trabajar con bases de datos usando objetos y consultas LINQ en C#.

¿Qué es LINQ?

Lenguaje integrado de consultas que permite manipular datos de manera declarativa dentro de C#.

Base de Datos Northwind

Base de datos de ejemplo utilizada para prácticas de sistemas de información y consultas relacionales.

Operaciones Unarias

Selección (σ)

Permite filtrar filas que cumplen una condición específica.

σ UnitPrice > 50 (Products)

var productos = db.Products .Where(p => p.UnitPrice > 50) .ToList();

Proyección (π)

Permite seleccionar columnas específicas de una tabla.

π ProductName, UnitPrice (Products)

var productos = db.Products .Select(p => new { p.ProductName, p.UnitPrice });

Renombramiento (ρ)

Permite cambiar nombres de atributos para mejorar claridad.

ρ NombreProducto, Precio (Products)

var productos = db.Products .Select(p => new { NombreProducto = p.ProductName, Precio = p.UnitPrice });
