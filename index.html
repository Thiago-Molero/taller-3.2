OPERACIONES BINARIAS DEL ÁLGEBRA RELACIONAL

Entity Framework + LINQ + Base de Datos Pubs

Las operaciones binarias permiten combinar y comparar información proveniente de distintas relaciones dentro de una base de datos relacional. En este taller se trabajó con la base de datos Pubs utilizando Entity Framework y consultas LINQ en C#.

Álgebra Relacional

Conjunto de operaciones matemáticas utilizadas para consultar y manipular datos dentro de bases de datos relacionales.

Entity Framework

ORM de Microsoft que permite trabajar con bases de datos mediante objetos y entidades en C#.

LINQ

Tecnología integrada en C# utilizada para realizar consultas declarativas sobre colecciones y bases de datos.

Base de Datos Pubs

Base de datos de ejemplo orientada al manejo de información relacionada con editoriales, autores, libros y ventas.

Operaciones Binarias

Unión (∪)

Combina los resultados de dos consultas compatibles en un único conjunto de datos eliminando registros duplicados.

Ejemplo:

Ciudades de autores ∪ ciudades de editoriales

Diferencia (−)

Permite identificar registros presentes en una consulta pero no en otra relación compatible.

Ejemplo:

Ciudades de autores − ciudades de editoriales

Producto Cartesiano (×)

Combina cada fila de una tabla con todas las filas de otra, generando todas las posibles combinaciones.

Ejemplo:

Autores × Títulos
